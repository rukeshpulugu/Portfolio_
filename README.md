# Rukesh Pulugu — Portfolio (plain HTML/CSS/JS)

No build step, no npm, no framework. Just open `index.html` in a browser, or host these files anywhere.

## Files
- `index.html` — all page content and structure
- `style.css` — all styling, colors, layout, dark/light mode
- `script.js` — all interactivity (theme toggle, animated formula bar, project filters/case studies, timeline, contact form) and your real content (edit the objects at the top of this file to update your bio/projects/experience)
- `images/rukesh.jpeg` — your photo
- `resume/Rukesh_Pulugu_Resume.pdf` — your resume (linked from the navbar)

## Run locally
Just double-click `index.html`, or for a local server:
```bash
npx serve .
```

## Deploy
Drag this folder into **Netlify Drop** (netlify.com/drop), or push it to a GitHub repo and enable **GitHub Pages** (Settings → Pages → Deploy from branch → main → / (root)). No build command needed — it's already static.

## Edit content
Open `script.js` and edit the `profile`, `skills`, `projects`, and `experience` objects near the top.
